고용24 — API는 불가, 직접 수집으로 해결 2026-08-20 시도·검증 기록

진행 경과 : 공공데이터포털에서 「한국고용정보원_워크넷 채용정보」 활용신청 시도 → 고용24(work24.go.kr) 자체 발급 절차로 연결 → OPEN-API 인증키 신청 화면까지 진입 → 신청 화면 안내문에서 제약 확인.

공고 화면 원문

"개인회원으로 채용정보API 신청 시 채용행사·공채속보·공채기업정보 API만 이용 가능하며, 채용정보목록·채용정보상세 API는 이용이 불가능합니다."

우리에게 필요한 채용정보목록·상세 API를 받으려면 민간(직업소개·직업정보제공기관) 자격으로 신청해야 하며, ①서비스 계획서 ②사업자등록증 ③직업정보제공사업 신고확인증 3종 서류 제출이 필요. ③은 잡코리아·사람인처럼 채용정보를 제3자에게 제공하는 사업자 등록으로, 도급업 사업자에게는 해당되지 않음.

결론 : API 발급은 보류하되, 사이트 직접 수집으로 완전히 해결됨.

✅ 대안 확인 : work24.go.kr 직접 수집 성공 2026-08-20 검증

API 없이 고용24 「채용정보 상세검색」 페이지를 직접 조회하는 방식으로 해결. 검색어 "룸메이드" + 지역필터 부산(region=26000) → 52건 조회, 이 중 신규 23건 수집 완료.

공고별 고유번호(wantedAuthNo)로 work24.go.kr 원문 URL을 직접 확보 — 사람인 경유가 아닌 정부 사이트 원문 링크. 현재 수집분 110건 중 고용24 38건(직접 23 + 사람인 경유 15).

※ 이 방식이 API보다 오히려 나은 점 : 서류·승인 절차 불필요, 웹에 노출되는 전체 공고를 그대로 수집. 단점 : 대량 자동화 시 사이트 부하를 고려해 수집 주기를 주 1회로 제한 권장.

※ 지엠네트웍스가 향후 직업정보제공사업 신고를 하게 되면 API도 정식 신청 가능.

사람인 오픈 API — 미신청 (불필요 판단)

발급처 : oapi.saramin.co.kr. 노출 범위가 웹 검색보다 좁고, 현재 브라우저 수집으로 충분히 커버되어 신청하지 않음. 필요 시 언제든 발급 가능.

🔄 구인공고 수집 방식 현재 운영 중인 절차

1
요청 시 실행 — "구인공고 갱신해줘" 요청 → 5개 사이트를 순회 검색 → 신규 공고만 추출 → 대시보드 데이터 갱신 → 웹사이트 자동 재배포.
2
중복 제거 — 이미 수집한 공고번호(사람인 rec_idx / 알바천국 adid / 잡코리아·알바몬 공고ID)를 대조해 신규만 누적. 기존 공고는 삭제하지 않음.
3
검증 규칙 — 부산 외 지역 제외 / 2025년 이하 공고 제외 / URL 없는 건 제외 / 업체명 미확인 건은 공고 상세페이지를 열어 사업자명·근무지 주소 확인.
4
주 1회 자동화 — 예약 작업으로 등록 가능. 요일·시간만 정해주시면 즉시 등록 (예: 매주 월요일 09:00 → 수집 → 갱신 → 결과 알림).
