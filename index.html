자동화 · 데이터 연동 가이드 "매번 실시간으로 바뀌게" 만드는 3단계 로드맵

🥇 1단계 — 지금 바로 가능 (API 불필요) : 클로드 수집 방식

1
요청 시 : 클로드에게 "구인공고 갱신해줘" 한 마디 → 사람인·고용24를 브라우저로 검색 → 이 HTML의 데이터 블록을 새 공고로 교체 → 파일 저장. 이번 제로 드래프트의 공고 데이터도 이 방식으로 수집한 실제 데이터임 (2026-08-19 수집 검증 완료).
2
주 1회 자동 : 클로드 코드 예약 작업(스케줄)으로 등록 — 예: 매주 월요일 09:00 자동 실행 → 수집 → 대시보드 갱신 → 완료 알림. 원하는 요일·시간대만 정해주면 바로 등록 가능.
3
검증 규칙 자동 적용 : 부산 외 지역 제외 / 2026년 이전 공고 제외 / URL 없는 건 제외 / 중복(같은 공고 재게시) 병합.

🥈 2단계 — API 발급 시 (무료) : 자동 수집 정확도 강화

① 고용24(워크넷) 채용정보 Open API 무료

발급처 : 공공데이터포털(data.go.kr) → "워크넷 채용정보" 검색 → 활용신청 (즉시승인)

기능 : 지역(부산 구별)·직종(음식숙박)·등록일 조건으로 공고 목록+상세 URL 조회. 룸메이드/하우스맨 공고의 상당수가 고용24 경유.

② 사람인 오픈 API 무료 (기업회원 키 발급)

발급처 : 사람인 오픈API (oapi.saramin.co.kr) → access-key 신청

기능 : 키워드+지역코드로 채용공고 검색 JSON 제공. 단, 노출 범위가 웹 검색보다 좁을 수 있어 브라우저 수집과 병행 권장.

③ 한국관광공사 TourAPI / 공공데이터포털 관광숙박업 데이터 무료

발급처 : 공공데이터포털 「전국 관광숙박시설 현황」 — 지역·업종·등급별 업체수/객실수 원본

기능 : 탭1~2의 전국 통계를 연 1회 자동 갱신 + 17개 시도 전체 채우기 + 부산 구별 호텔 리스트.

④ KOSIS 공유서비스 OpenAPI (통계청) ✅ 발급완료 · 호출검증 완료 (2026-08-20)

인증키는 같은 폴더의 api_config.json에 저장 (호출 URL·분류코드표 포함). 아웃소싱 공급시장 탭의 전국사업체조사 수치를 신규 연도 발표 시 자동 갱신.

검증 : 2024년 전국 741업종 6,507개 / 부산 293개 — 대시보드 수치와 API 응답 일치 확인.

💡 현황 : ④ KOSIS 연동 완료 · ① 고용24 API는 개인회원 제약(채용정보목록 API는 직업정보제공사업 신고 기관만 가능)으로 보류 — 브라우저 수집으로 대체 (고용24 연계 공고도 사람인 검색에 포함됨) · ③ 관광숙박 파일데이터는 키 불필요 · ② 사람인은 선택사항.

🥉 3단계 — 장기 : 상시 서버 (busan-lab 방식)

S
기존 카페 상권랩(busan-lab.onrender.com)처럼 Render 무료 서버에 올려서, 대시보드를 열 때마다 서버가 고용24 API를 직접 호출 → 진짜 실시간. HTML 파일 단독으로는 브라우저 보안정책(CORS) 때문에 채용사이트를 직접 호출할 수 없어서, 실시간을 원하면 이 단계가 최종형. 1~2단계로 운영해보고 필요하면 진행 권장.

📬 주간 리포트 알림 포맷 (자동 발송안)
